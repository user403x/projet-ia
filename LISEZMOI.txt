HelvetiaTax IA – version GitHub Pages (IA via Gemini)
=====================================================
Fichiers à mettre à la racine du dépôt GitHub « projet-ia » :
  index.html, config.js, kb.json

1. Créer une clé gratuite sur aistudio.google.com (Get API key).
2. Dans Google Cloud (console > APIs & Services > Credentials), restreindre la clé :
   « Application restrictions » = Websites, referrer https://user403x.github.io/*
3. Ouvrir config.js et coller la clé entre les guillemets de geminiKey.
4. Déposer les 3 fichiers sur GitHub (Add file > Upload files > Commit), ou remplacer
   les fichiers existants.
5. Attendre 1 à 2 minutes puis ouvrir https://user403x.github.io/projet-ia/ :
   en haut à droite, « IA active » doit apparaître.
